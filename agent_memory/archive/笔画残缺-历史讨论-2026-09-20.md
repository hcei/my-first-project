用户报「欲穷千里目」真机出现口缺折笔/里缺一横/目短横过短/千竖变提/宀围合太小；三组对照（A 速度2顿笔开=结构完整但炸毛、B 速度2顿笔关=复现残缺、C 速度1顿笔关=基本正确但颤抖）。本 agent 复核结论（完整版见 `C:/Users/ceiii/.qoderwork/workspace/mu9q48io11r958my/outputs/书写残缺问题-交叉讨论回复.md`）：
- **主因＝Z 过渡没有时间**：每笔落笔是 40mm 下扎（Z_UP=-325→书写平面-365）、抬笔是 40mm 提起，而顿笔关时 `get_Z_SETTLE_MS` 等一律返回 0 → 该两条指令只分到 **12ms**（真机被串口往返撑到 ~45ms）。短笔画整笔 0.6~1.5s 而两端 Z 过渡要 0.4~0.8s → 笔整笔处在"还在扎下去/已经开始提起来"的瞬态：**缺横/过短**由此而来；抬笔提前 + XY 追赶 → **竖变提**。
- **顿笔开之所以治好**：4 个**同 XY** 的分层点 + 端点 dwell = 在笔画端点强制重同步 **626ms(落)/464ms(抬)**；**与压力无关**——`writing_plane_valid=true` 时 `zdown=-365` 恒定，顿笔开/关深度相同。每笔多耗 ~1.1s。
